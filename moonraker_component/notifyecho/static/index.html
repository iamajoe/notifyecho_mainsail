NotifyEcho

Klipper print notifications from Moonraker

Connection

Use your project's bearer key from NotifyEcho.

Create the workflows in NotifyEcho first. Each workflow's trigger kind must match the kind shown next to its event below.

Workflow routing

Default mode sends every enabled event to one workflow. Advanced mode lets each event use its own workflow ID; blank falls back to the default.

Events

Every event is enabled by default. Disable any event you do not want sent.

Updates

Keep NotifyEcho current. Only tagged releases can be updated, and updates always require an explicit click. Moonraker restarts when an update finishes.
